# Revision Notes — Index

**Single place for quick review before weekly tests, mock interviews, and system-design sessions.**

Open this folder the night before any assessment. Prefer compressed bullets over full daily notes.

---

## How to use

1. After each day → update [`by-week/week-XX.md`](by-week/)
2. After each section → write [`by-section/section-X.md`](by-section/)
3. After every wrong answer → add to [`mistakes-log/`](mistakes-log/)
4. After architecture choices → log in [`decisions/`](decisions/)
5. Stable formulas / APIs → [`cheatsheets/`](cheatsheets/)
